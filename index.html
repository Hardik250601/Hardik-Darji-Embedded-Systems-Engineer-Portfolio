// How this site is built

Built with

This portfolio has no framework and no build step on the server — it is hand-written HTML, CSS and JavaScript, served as static files. The same discipline that keeps firmware debuggable keeps a site maintainable.

Frontend

HTML5 · CSS3 · Vanilla JS

No React, Vue or Angular. Zero runtime dependencies in the browser.

Styling

Tailwind CSS

Compiled to a minified stylesheet that is committed, so hosting needs no build step.

Backend

Node.js

One serverless function connects newsletter signups to Buttondown (API key required).

Hosting

Vercel

Auto-deploys on every push. Also ships an RSS feed and an OG image per post.

Every page is checked by a static, API and DOM test suite before it ships — npm run verify
